# Repo Conventions

## File Size Limits (Code)

- Keep **code files** under **300 lines** ideally.
- **Hard limit:** no code file may exceed **500 lines**.
- Exclusions are allowed only when necessary and must be explicitly listed in `.githooks/loc-limit-exclude.txt`.
- This rule does **not** apply to autogenerated files (for example anything under `**/obj/**` or `**/bin/**`, or `*.g.cs`, `*.designer.cs`) and does not apply to non-code files.
