# `system`

- Root: [index](../index.md)
- Parent: [](../index.md)

JDownloader, OS, and update operations.

## Subcommands

- [info](info.md) — Show JDownloader system info.
- [jd](jd/index.md) — JDownloader lifecycle operations.
- [os](os/index.md) — Operating system power operations.
- [reconnect](reconnect.md) — Trigger reconnect.
- [storage](storage.md) — Show storage info.
- [toggle](toggle.md) — Toggle common JDownloader state flags.
- [update](update/index.md) — Update lifecycle operations.

## Examples

- `system info --dry-run`
