# `system os`

- Root: [index](../../index.md)
- Parent: [system](../index.md)

Operating system power operations.

## Subcommands

- [hibernate](hibernate.md) — Hibernate the operating system.
- [shutdown](shutdown.md) — Shutdown the operating system.
- [standby](standby.md) — Put the operating system into standby.

## Examples

- `system os shutdown --force`
