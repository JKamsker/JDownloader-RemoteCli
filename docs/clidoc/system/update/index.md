# `system update`

- Root: [index](../../index.md)
- Parent: [system](../index.md)

Update lifecycle operations.

## Subcommands

- [check](check.md) — Check whether updates are available.
- [restart](restart.md) — Restart and apply updates.
- [run](run.md) — Run update check.

## Examples

- `system update check --dry-run`
