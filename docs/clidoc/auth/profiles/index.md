# `auth profiles`

- Root: [index](../../index.md)
- Parent: [auth](../index.md)

Manage saved CLI profiles.

## Subcommands

- [add](add.md) — Create a new profile.
- [get](get.md) — Show a saved profile.
- [list](list.md) — List saved profiles.
- [remove](remove.md) — Remove a profile and its device defaults.
- [rename](rename.md) — Rename an existing profile.
- [use](use.md) — Set the default profile.

## Examples

- `auth profiles list --dry-run`
