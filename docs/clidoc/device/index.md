# `device`

- Root: [index](../index.md)
- Parent: [](../index.md)

Resolve, inspect, and select JDownloader devices.

## Subcommands

- [direct-info](direct-info.md) — Show direct connection info for the resolved device.
- [get](get.md) — Show the currently resolved device.
- [list](list.md) — List devices visible to the current account.
- [ping](ping.md) — Ping the resolved device (0-arg endpoint).
- [use](use.md) — Set the default device for a profile.

## Examples

- `device list --dry-run`
