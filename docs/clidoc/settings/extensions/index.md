# `settings extensions`

- Root: [index](../../index.md)
- Parent: [settings](../index.md)

Inspect and manage extensions.

## Subcommands

- [disable](disable.md) — Disable an extension by id or classname.
- [enable](enable.md) — Enable an extension by id or classname.
- [get](get.md) — Get an extension by id or name.
- [install](install.md) — Install an extension by id.
- [list](list.md) — List extensions.

## Examples

- `settings extensions list --query-json {}`
