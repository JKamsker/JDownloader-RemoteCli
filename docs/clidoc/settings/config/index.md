# `settings config`

- Root: [index](../../index.md)
- Parent: [settings](../index.md)

Read and update config values.

## Subcommands

- [get](get.md) — Get a config entry.
- [list](list.md) — List config entries for an interface.
- [reset](reset.md) — Reset a config entry to default.
- [set](set.md) — Set a config entry.

## Examples

- `settings config list --pattern example`
