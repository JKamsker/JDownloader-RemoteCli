# `connection`

- Root: [index](../index.md)
- Parent: [](../index.md)

Manage saved connections: direct (local JDownloader API) or My.JDownloader.

## Subcommands

- [add](add.md) — Create or update a connection (--mode direct|myjd).
- [get](get.md) — Show a saved connection.
- [list](list.md) — List saved connections with their mode and endpoint.
- [remove](remove.md) — Remove a saved connection.
- [test](test.md) — Probe the resolved connection (ping, version, download state) and report latency.
- [use](use.md) — Set the default connection.

## Examples

- `connection list --dry-run`
