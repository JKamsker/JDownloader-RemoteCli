# `downloads stopmark`

- Root: [index](../../index.md)
- Parent: [downloads](../index.md)

Inspect and manage download stopmarks.

## Subcommands

- [clear](clear.md) — Clear the stopmark.
- [get](get.md) — Get the current stopmark.
- [set](set.md) — Set the stopmark (requires link + package id).

## Examples

- `downloads stopmark get --dry-run`
