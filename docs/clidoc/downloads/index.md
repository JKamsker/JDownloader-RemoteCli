# `downloads`

- Root: [index](../index.md)
- Parent: [](../index.md)

Inspect and control active downloads.

## Subcommands

- [links](links/index.md) — Inspect and manage download links.
- [packages](packages/index.md) — Inspect and manage download packages.
- [pause](pause.md) — Pause downloads (or resume with --resume).
- [speed](speed.md) — Show current aggregated download speed.
- [start](start.md) — Start downloads.
- [status](status.md) — Show download controller status.
- [stop](stop.md) — Stop downloads.
- [stopmark](stopmark/index.md) — Inspect and manage download stopmarks.

## Examples

- `downloads status --dry-run`
