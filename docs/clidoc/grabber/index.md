# `grabber`

- Root: [index](../index.md)
- Parent: [](../index.md)

Manage linkgrabber ingestion and staging.

## Subcommands

- [add](add.md) — Add links to the linkgrabber.
- [add-container](add-container.md) — Add a container file to the linkgrabber.
- [clear](clear.md) — Clear the linkgrabber list (0-arg endpoint).
- [jobs](jobs/index.md) — Inspect crawler jobs.
- [links](links/index.md) — Inspect and manage linkgrabber links.
- [move-to-downloads](move-to-downloads.md) — Move linkgrabber selection into downloads.
- [packages](packages/index.md) — Inspect and manage linkgrabber packages.
- [variants](variants/index.md) — Inspect and set variants for crawl results.

## Examples

- `grabber add --url https://example.invalid/file`
