# `grabber variants`

- Root: [index](../../index.md)
- Parent: [grabber](../index.md)

Inspect and set variants for crawl results.

## Subcommands

- [list](list.md) — List variants for a linkgrabber link id.
- [set](set.md) — Select a variant for a linkgrabber link.

## Examples

- `grabber variants list --link-id 1`
