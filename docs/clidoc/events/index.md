# `events`

- Root: [index](../index.md)

Inspect and manage event subscriptions.

## Subcommands

- [listen](listen.md) — Listen for events on a subscription id.
- [publishers](publishers.md) — List event publishers.
- [remove](remove.md) — Remove subscription content.
- [set](set.md) — Set subscription content.
- [status](status.md) — Get subscription status.
- [subscribe](subscribe.md) — Create a new subscription.

## Examples
