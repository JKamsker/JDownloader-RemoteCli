# `accounts`

- Root: [index](../index.md)
- Parent: [](../index.md)

Manage premium accounts and basic-auth entries.

## Subcommands

- [add](add.md) — Add an account.
- [basic-auth](basic-auth/index.md) — Manage HTTP/FTP basic-auth entries.
- [disable](disable.md) — Disable accounts by id.
- [enable](enable.md) — Enable accounts by id.
- [get](get.md) — Deprecated alias for 'accounts hosters url'; kept for backwards compatibility.
- [hosters](hosters/index.md) — Inspect premium hosters.
- [list](list.md) — List accounts.
- [refresh](refresh.md) — Refresh accounts by id.
- [remove](remove.md) — Remove accounts by id.
- [update](update.md) — Update username/password for an account id.

## Examples

- `accounts list --query-json {}`
