# `accounts hosters`

- Root: [index](../../index.md)
- Parent: [accounts](../index.md)

Inspect premium hosters.

## Subcommands

- [list](list.md) — List premium hosters.
- [url](url.md) — Resolve a premium hoster name to its account URL.
- [urls](urls.md) — List premium hoster URLs.

## Examples

- `accounts hosters list --dry-run`
