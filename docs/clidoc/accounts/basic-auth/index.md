# `accounts basic-auth`

- Root: [index](../../index.md)
- Parent: [accounts](../index.md)

Manage HTTP/FTP basic-auth entries.

## Subcommands

- [add](add.md) — Add a basic-auth entry.
- [list](list.md) — List basic-auth entries.
- [remove](remove.md) — Remove basic-auth entries by id.
- [update](update.md) — Update a basic-auth entry.

## Examples

- `accounts basic-auth list --dry-run`
