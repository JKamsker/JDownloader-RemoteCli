# `advanced content`

- Root: [index](../../index.md)
- Parent: [advanced](../index.md)

Binary icons and content endpoints.

## Subcommands

- [describe](describe.md) — Describe an icon key.
- [favicon](favicon.md) — Fetch a favicon by hoster name (binary).
- [file-icon](file-icon.md) — Fetch a file icon by filename (binary).
- [icon](icon.md) — Fetch an icon by key (binary).

## Examples

- `advanced content icon --output-file ./sample`
